What's Changed

A running record of every update made to the Mun-Hwa Bu platform, and what's planned next.

This starts from when detailed build records began being kept — it doesn't cover the platform's full history from before that point.
27 August 2026
Media Desk
  • Added a mandatory sign-out checklist: deleted desktop downloads, deleted Telegram downloads folder, logged out of Telegram, logged out of the PC — all four must be confirmed before signing out
  • Removed the camera-only restriction on sign-out photos — the device's normal choice of "take a photo" or "choose existing" is now available again
Team Checkout
  • Return confirmation messages now list exactly what was returned, pulled from the original checkout record — previously only the photo showed this
Equipment Rental (Mun-Hwa Bu Requests)
  • Added a required "Date Equipment is Needed For" field, separate from pickup/return dates, and surfaced it in the review screen, admin view, and daily summary
  • Added a required "Do you require Mun-Hwa Bu assistance to set up?" question — shown as a prominent flagged callout in the admin dashboard when answered Yes, not just a quiet field
Equipment Return Portal
  • Now supports uploading multiple photos instead of just one, so returns to more than one location can be properly documented
  • Removed the camera-only restriction so an existing photo can be uploaded, not just a freshly captured one
Admin Dashboard
  • Approve/Reject buttons now disappear once a request is no longer pending, preventing the exact mix-up between "Approve" and "Log Items Given" reported after a real approval
Daily Summary Report
  • Added an "Equipment Activity Today" section — what was checked out today, and what was confirmed returned today
  • Added a "Requests" section — everything still awaiting approval, and everything approved that same day
  • Added Approval Date tracking to the Support Requests sheet to make "approved today" answerable at all
Fixed
  • Traced and corrected a serious, cascading column-misalignment bug: every Props, Material, Video, and Design field in the request sheet had been writing one column to the left of its label since an earlier form change — 27 fields were being silently discarded on every submission and have now been restored
  • Fixed the Approve/Reject buttons writing status into the wrong sheet column entirely (overwriting Request Types instead of Status) — approvals had never actually been recorded correctly
  • Admin dashboard's request detail view now actually displays the type-specific fields for every request type (previously showed only generic wrapper fields, regardless of what was submitted)
24–26 August 2026
Added — Equipment Rental Fulfillment
  • New capability for tracking external Equipment Rental requests end-to-end: Culture logs exactly what was handed over (with a photo), and the external team can log the return themselves — including where the equipment was left — even if Culture isn't there to receive it in person
  • New dedicated "Equipment Rental Log" sheet, separate from internal Team Checkouts
  • New public return portal (no password needed), reachable via a direct link that pre-fills everything so there's no manual lookup step
  • "Log Items Given" built into the existing Admin Dashboard rather than a separate tool, appearing only once a request is Approved
Daily Summary Report
  • Replaced the old weekly Sunday-only equipment report with a genuine daily summary covering equipment status and Media Desk activity together
  • Overdue equipment now gets flagged every day until it's actually returned, rather than a one-time notice
Media Desk
  • Added an "All of the above" option for equipment operated solo, with the "Is anyone assisting you?" question moved above it so it's seen first
  • Selecting "Yes" to assistance now automatically clears "All of the above" and forces a genuine reselection — nobody can complete sign-in with a stale "I did it all myself" answer once help is involved
  • Fixed oversized native radio buttons overlapping their labels on iOS, across every form on the site
Fixed
  • Traced the actual root cause of a long-running mystery: the Sunday Report, daily reminders, admin dashboard, and "Mark Returned" button were all quietly reading from an unused legacy sheet instead of the real one everything actually writes to — all four now read the correct data
  • Fixed silent failures in Telegram photo delivery — a rejected photo (oversized, malformed) previously vanished with no error and no fallback message; now it's detected and a text-only message is sent instead so the notification is never lost entirely
  • Fixed submissions timing out too aggressively on slower connections, and replaced the generic "Something went wrong" message with an honest one that distinguishes "this may have still gone through" from "this definitely didn't send"
  • Added client-side photo compression across every upload point — uncompressed phone photos were causing slow uploads and Telegram rejections
  • Added an admin dashboard performance fix: it was re-fetching all three data sheets on every login and every click, regardless of which tab was open; now it only loads what's being viewed, with caching
  • Added a "Find & Return" option to Team Checkout for when the original Telegram return link has been lost — search by name instead
20–22 August 2026
Added
  • Restructured the Mun-Hwa Bu New Request form into four clear steps (Your Details → Request Type → Request Details → Confirm), replacing an earlier layout where the review step could be reached too easily by accident
  • Equipment Rental switched from a fixed quantity-clicker list to free-text item entry with quantities, matching the pattern used in Team Checkout
  • Automatic Telegram topic routing — Requests, Checkouts, and Media Desk now post to their own dedicated topics instead of one shared feed
  • Client-side error reporting — unexpected JavaScript errors now report themselves directly to a private channel instead of failing silently
  • Server-side validation added to the request form to back up client-side checks
Fixed
  • Diagnosed and fixed a serious HTML nesting bug from a stray extra closing tag that let the "Review Request" step render outside its intended step, regardless of which step a user was actually on — affected every visitor to the live form
  • Removed a large block of dead code in Team Checkout left over from an earlier design (a catalogue-based item picker) that was silently wiping the real item list on page load
  • Added Enter-to-add-next-row behaviour for equipment item entry, working consistently regardless of how a row was created
